# BLOOM — цветы, которые говорят за вас

Одностраничный интернет-магазин цветов на чистом HTML, CSS и JavaScript: без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере — или запустите локальный сервер:

```bash
npx http-server -p 8080
# либо
python3 -m http.server 8080
```

и перейдите на http://localhost:8080.

## Возможности

- Фиксированная шапка, которая уменьшается при прокрутке, и мобильное меню (hamburger)
- Каталог из 15 букетов: фильтр по категории и цене, сортировка, фильтр по поводу из карточек «Что вы ищете?»
- Карточка товара в модальном окне: размер S / M / L с пересчётом цены и состава, количество, избранное
- Конструктор букета с живым превью: цветы, цвет, размер, упаковка, дополнения, автоматический расчёт цены
- Боковая корзина: количество, удаление, расчёт доставки (бесплатно от 25 000 ₸), шкала до бесплатной доставки
- Оформление заказа с валидацией, маской телефона, выбором оплаты и генерацией номера заказа
- Избранное, поиск по товарам (с учётом словоформ: «розы», «роза», «розовые»)
- Форма доставки (данные подставляются в заказ), анонимный подарок, отзывы-слайдер, FAQ, подписка
- Корзина, избранное и данные форм сохраняются в `localStorage`
- Адаптивность от 320 px, анимации появления, уважение к `prefers-reduced-motion`

## Структура

```
index.html            — разметка всех секций и модальных окон
css/style.css         — дизайн-система и адаптивные стили
js/data.js            — товары, пути к фото, конструктор, отзывы, FAQ
js/app.js             — логика магазина
js/map.js             — схематичная карта для блока «Контакты»
images/               — фотографии (список файлов и требования — images/README.md)
tools/check-images.js — показывает, каких фото не хватает
```

## Фотографии

Все изображения — это фото из папки `images/`:

- товары: `images/products/<id>.jpg`;
- первый экран, «О нас», поводы и превью конструктора — там же.

Пока файла нет, на его месте показывается аккуратный плейсхолдер с названием и путём. Положите фото с нужным именем, и оно появится на сайте само.

Что снимать для каждого товара, требования к фото, ссылки на бесплатные стоки и промпты для нейросетей — в [images/README.md](images/README.md).

```bash
node tools/check-images.js   # список недостающих фото
```
